# HyperKids OptoJump · Windows

## Εγκατάσταση
1. Αποσυμπίεσε τον φάκελο σε μόνιμη θέση στα Windows.
2. Εγκατάστησε Python 3.11 ή νεότερη από https://www.python.org/downloads/windows/ αν δεν υπάρχει.
3. Άνοιξε το Install.cmd μία φορά. Εγκαθιστά τις απαραίτητες βιβλιοθήκες σε απομονωμένο περιβάλλον.
4. Άνοιξε το Start.cmd και συνδέσου με τον λογαριασμό admin της πλατφόρμας. Δεν χρησιμοποιείται ιδιωτικό κλειδί βάσης.
5. Πάτησε «Επιλογή φακέλου» και επίλεξε τον φάκελο στον οποίο εξάγεις XML από το OptoJump.
6. Πάτησε «Αντιστοίχιση χρήστη», επίλεξε XML και τον χρήστη OptoJump, γράψε το email του στην πλατφόρμα και επιβεβαίωσε το όνομα. Η αντιστοίχιση αποθηκεύεται με το δικό μας User ID.
7. Πάτησε «Έναρξη μεταφοράς». Θα μεταφερθούν και τα υπάρχοντα υποστηριζόμενα τεστ του φακέλου, με επιβεβαίωση πριν ξεκινήσει η μεταφορά.

## Τι μεταφέρεται
- SQUAT JUMP → Non-Counter Movement Jump (cm).
- CMJ → Counter Movement Jump (cm).
- DROP JUMP → Depth Jump (cm).
- Διατηρούνται ημερομηνία/ώρα, αριθμός προσπάθειας, χρόνος πτήσης, χρόνος επαφής και RSI όταν υπάρχουν.
- Κάθε προσπάθεια δημιουργεί δικό της τεστ στο υπάρχον ιστορικό αλμάτων. Οι χρόνοι και το RSI διατηρούνται στις σημειώσεις και στην αρχική καταγραφή.
- CMJ FREE ARMS και άλλοι τύποι αναφέρονται ως μη υποστηριζόμενοι: δεν συγχωνεύονται με CMJ.
- Πρόσθετες σειρές θέσης χωρίς Elevation/Flight time δεν γίνονται αποτελέσματα αλμάτων.

## Ασφάλεια και συμπεριφορά
Η πρώτη έκδοση λειτουργεί μόνο με admin και χρήστες που ανήκουν στο admin, όχι σε Coach/Club. Οι έλεγχοι γίνονται στη βάση, όχι μόνο στο laptop. Η σύνδεση αποθηκεύεται στο Windows Credential Manager· ο κωδικός δεν αποθηκεύεται σε αρχείο. Πατώντας «Αποσύνδεση» αφαιρείται η αποθηκευμένη σύνδεση.

Ο φάκελος ελέγχεται κάθε 3 δευτερόλεπτα. Ένα XML διαβάζεται αφού το μέγεθος και η ημερομηνία αλλαγής του μείνουν σταθερά για έναν έλεγχο. Σε διακοπή Internet τα αποτελέσματα μένουν στο αρχείο και η αποστολή επαναλαμβάνεται αυτόματα. Μην διαγράψεις ή μετακινήσεις το XML πριν επιβεβαιωθεί η αποθήκευση. Δεν σβήνεται ούτε μετακινείται κανένα αρχείο OptoJump.

Η αποθήκευση στη βάση είναι ατομική και αναγνωρίζει ξανά την ίδια προσπάθεια ακόμη κι αν εξαχθεί σε άλλο αρχείο ή από άλλο laptop. Αν αλλάξουν μετρήσεις ή αντιστοίχιση ήδη εισαγμένης προσπάθειας, απαιτείται έλεγχος αντί να δημιουργηθεί δεύτερη εγγραφή ή να αντικατασταθούν αθόρυβα αποτελέσματα.

Το πρόγραμμα πρέπει να παραμένει ανοιχτό. Δεν ενεργοποιείται αυτόματα με τα Windows στην πρώτη έκδοση. Το κουμπί «Έναρξη μεταφοράς» δεν ξεκινά τη συσκευή: οι μετρήσεις και η εξαγωγή γίνονται στο OptoJump. Δεν έχει υλοποιηθεί ακόμη εντολή έναρξης από την πλατφόρμα.

## Έλεγχοι
Από αυτόν τον φάκελο: `python -m unittest discover -s tests -v`.
Η ανάγνωση ελέγχθηκε με το παρεχόμενο XML. Η πραγματική σύνδεση/μεταφορά και η εκτέλεση στα Windows χρειάζονται τελική δοκιμή στο laptop.
